# AI, ale po mém

Jeden nápad, jedna webovka a z ní čtyři animované reely v různých stylech (AI v praxi, barevný UI reel a dvě varianty kinetického reelu). Vytvořeno s Claude.

Živá verze: https://evavclaude.evirtualniasistentka.workers.dev/

## Jak to funguje
- Celá stránka je jeden soubor `public/index.html`. Animace i obrázky jsou v něm vložené, nic se neinstaluje.
- Běží na Cloudflare Workers jako statické soubory, nastavení je v `wrangler.jsonc`.
